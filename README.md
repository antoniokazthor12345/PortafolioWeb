## 📦 Instalación local

Clonar repositorio:

```bash
git clone https://github.com/antoniokazthor12345/PortafolioWeb.git
```

Instalar dependencias:

```bash
npm install
```

Ejecutar en desarrollo:

```bash
npm run dev
```

Compilar producción:

```bash
npm run build
```
